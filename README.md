
# OtthonRadar — Official Privacy Policy

Official GitHub Pages website and privacy policy for
**OtthonRadar: Ingatlankereső**.

OtthonRadar is a Hungarian-language, map-based real estate
search application for Android phones and tablets.

## Application

- App name: OtthonRadar: Ingatlankereső
- Package ID: `com.mdl1000.otthonradar`
- Platform: Android
- Main language: Hungarian

## Features

- Map-based real estate searches
- Properties for sale: apartments, houses, and land
- Properties for rent: apartments and houses
- Holiday accommodation searches
- Adjustable search radius
- Sorting by distance or price
- Support for phones and tablets

Search results depend on available third-party listing
sources and may be incomplete or change over time.

## Privacy Policy

This repository hosts the public English-language
Privacy Policy required for the Google Play listing.

After GitHub Pages is enabled, the expected URL is:

https://davidmenyhert.github.io/OtthonRadar/

The `index.html` file contains the Privacy Policy.

## Publishing with GitHub Pages

1. Create a public GitHub repository named `OtthonRadar`.
2. Upload `index.html` and `README.md` to its root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
5. Save the settings.
6. Open the public URL above to verify the page.

Enter that URL in the Google Play Console under
the app's Privacy Policy field.

## Advertising

OtthonRadar uses Google AdMob.

The publisher's domain-level `app-ads.txt` file should
remain at the root of the GitHub Pages domain, if that
domain is used as the developer website:

https://davidmenyhert.github.io/app-ads.txt

Placing `app-ads.txt` inside `/OtthonRadar/` does not
replace the domain-root file.
